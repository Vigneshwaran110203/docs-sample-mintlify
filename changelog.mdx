<Update label="October 26, 2026" description="Week of October 19">
  ## New features

  - **Task priority:** Task responses now include a `priority` field with a value of `low`, `medium`, or `high`. You can see how urgent a task is in a single request. See [Task priority](/guides/task-priority) and [Get a task](/guides/tasks).
  - **Task due dates:** Task responses now include a `due_date` field in `YYYY-MM-DD` format. You can track deadlines directly from the task object. See [Get a task](/guides/tasks).
</Update>
