# TaskFlow Changelog

This page lists new features, improvements, and fixes released
in TaskFlow.

<Update label="October 26, 2026" description="Week of October 26">
  ## New features

  - **Task due dates:** Task responses now include a `due_date` field in `YYYY-MM-DD` format, such as `2026-11-05`. You can track deadlines directly from the task object. See [Get a task](/guides/tasks).
</Update>
