# Installation

You do not need to install an SDK. Use a browser, `curl`, Postman, or Thunder Client.

## Verify access

```bash
curl https://jsonplaceholder.typicode.com/todos/1
```

## Preview this documentation locally

Run these commands from the folder containing `docs.json`:

```bash
npm install -g mint
mint dev
```

Then open `http://localhost:3000`.
