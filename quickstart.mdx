# Quickstart

## 1. Send a request

```bash
curl https://jsonplaceholder.typicode.com/todos/1
```

## 2. Example response

```json
{
  "userId": 1,
  "id": 1,
  "title": "delectus aut autem",
  "completed": false
}
```

## 3. Try the playground

Open **API reference → Get a task**, set `id` to `1`, and send the request.

<Warning>JSONPlaceholder is a mock API. Create, update, and delete requests simulate responses; they do not save changes permanently.</Warning>
