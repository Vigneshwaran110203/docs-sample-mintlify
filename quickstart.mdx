# Quickstart

This guide demonstrates how a product quickstart can be structured.

<Steps>
  <Step title="Create an account">
    Open the TaskFlow application and choose **Create account**.
  </Step>
  <Step title="Create a workspace">
    Give your workspace a clear name, such as `my-team`.
  </Step>
  <Step title="Create a task">
    Add a task with a title, an owner, and a due date.
  </Step>
  <Step title="Review your task">
    Open the task and confirm that its details are correct.
  </Step>
</Steps>

## Example data

```json
{
  "title": "Prepare release notes",
  "status": "in_progress",
  "priority": "high"
}
```

<Note>
  The example describes fictional TaskFlow data. It is not a working API request.
</Note>
