# Manager demo checklist

- [ ] Homepage and navigation look correct.
- [ ] Quickstart and guide pages render.
- [ ] Search finds a guide on the hosted site.
- [ ] API reference loads from `openapi.json`.
- [ ] `GET /todos/1` returns sample data.
- [ ] Write operations are explained as simulated.
- [ ] No real credentials or private data are included.
- [ ] Starter and paid features are clearly distinguished.

## Suggested explanation

"This is a fictional developer documentation portal built with Mintlify Starter. It demonstrates docs-as-code, MDX components, navigation, search, SEO metadata, and an OpenAPI-powered API playground. The playground uses a public mock API, so write operations do not persist."
