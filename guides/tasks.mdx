# Get a Task

Use `GET /tasks/1` to retrieve a task.

## Example response

```json
{
  "id": 1,
  "title": "Prepare report",
  "priority": "high"
}
```

The response contains the task ID, title, and priority. The `priority` field is a string set to `low`, `medium`, or `high`. See [Task priority](/guides/task-priority) to change it.
