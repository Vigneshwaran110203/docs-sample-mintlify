# Get a Task

Use `GET /tasks/1` to retrieve a task.

## Example response

```json
{
  "id": 1,
  "title": "Prepare report",
  "priority": "high",
  "due_date": "2026-11-05"
}
```

The response contains the task ID, title, priority, and due date. The `priority` field is a string set to `low`, `medium`, or `high`. See [Task priority](/guides/task-priority) to change it.

The `due_date` field is a string in `YYYY-MM-DD` format that shows when the task is due. For example, `2026-11-05` means the task is due on November 5, 2026.
