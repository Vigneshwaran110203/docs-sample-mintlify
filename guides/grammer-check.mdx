# Create a Task

TaskFlow allow users to creates new task.

To create a task, follow this steps:

1. Open the TaskFlow dashboard.
2. Click the **Create Task** button.
3. Enter the task title and click **Savee**.
4. The task are now created successfuly.

## Important Notes

- You must enters a title before creating a task.
- The task details is saved automatically.
- If you has an error, check your internet connection.

Contact support if you need any helps.
