# Create a Task

TaskFlow allows users to create new tasks.

To create a task, follow these steps:

1. Open the TaskFlow dashboard.
2. Click the **Create Task** button.
3. Enter the task title and click **Save**.
4. The task is now created successfully.

## Important Notes

- You must enter a title before creating a task.
- The task details are saved automatically.
- If you have an error, check your internet connection.

Contact support if you need any help.
