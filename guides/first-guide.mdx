# Create your first task

Use this guide as a template for future how-to documentation.

## Before you begin

- You have access to a TaskFlow workspace.
- You know the title of the task you want to create.

## Instructions

1. Open your workspace.
2. Select **New task**.
3. Enter a descriptive title.
4. Add any relevant details.
5. Select **Save**.

## Troubleshooting

<AccordionGroup>
  <Accordion title="I cannot find the New task button">
    Check that you are inside a workspace and that your account has permission to create tasks.
  </Accordion>
  <Accordion title="My changes did not appear">
    Refresh the page and check whether the task was saved successfully.
  </Accordion>
</AccordionGroup>

## Next step

After creating a task, practise editing it and changing its status.
